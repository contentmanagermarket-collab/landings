# Лендинг «Экосфера» для Pirelli

Готовый адаптивный одностраничный сайт на чистом HTML, CSS и JavaScript. Все фотографии хранятся локально в папке `assets`.

## Запуск

Для просмотра без локального сервера можно открыть `index.html` в браузере.

Для локального теста:

```powershell
python -m http.server 4173
```

Затем открыть `http://127.0.0.1:4173/`.

## Структура

- `index.html` — содержание и семантическая разметка.
- `styles.css` — визуальная система и адаптивная вёрстка.
- `script.js` — мобильное меню, подсветка навигации и мягкое появление блоков.
- `assets` — фотографии «Экосферы», Pirelli и команды.

## Размещение

Папку можно загрузить на любой статический хостинг. Сборка и установка зависимостей не требуются.
