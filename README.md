# Сайты-презентации «ЭкоСферы»

В этом репозитории собраны готовые сайты-презентации «ЭкоСферы» для заказчиков и партнёров. Каждый проект работает как самостоятельная адаптивная страница на HTML, CSS и JavaScript.

## Презентации

- [«ЭкоСфера» для Pirelli](https://contentmanagermarket-collab.github.io/landings/) — `index.html`
- [Опыт «ЭкоСферы» в Сбере](https://contentmanagermarket-collab.github.io/landings/sber.html) — `sber.html`

## Структура

- `index.html`, `styles.css`, `script.js` — презентация для Pirelli;
- `sber.html`, `sber.css`, `sber.js` — презентация опыта работы со Сбером;
- `assets` — изображения и другие материалы презентации Pirelli;
- `assets/sber` — фотографии, изображения и видео для презентации Сберу.

Все материалы хранятся внутри репозитория. Дополнительная сборка и установка зависимостей не требуются.
